# 云雀飞行

浏览器里的单人三维轻型飞机飞行模拟。飞机从跑道头开始，可以滑跑起飞、空中飞行、对准跑道降落；接地过重或姿态不好会坠毁，然后重新开始。

**在线试玩：** [https://jinzi2025666-dotcom.github.io/yunque-flight/](https://jinzi2025666-dotcom.github.io/yunque-flight/)

线上页面来自 `main` 分支的 [`docs/index.html`](docs/index.html)（GitHub Pages，发布目录 `/docs`）。若链接暂时打不开，到仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，分支 `main`、目录 `/docs`，保存后等一两分钟。本地开发用下面的 Vite 源码。

## 运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run start
```

浏览器打开 [http://127.0.0.1:47821](http://127.0.0.1:47821)。

也可以先构建再预览：

```bash
npm run build
npm run preview
```

`npm run check` 会跑一轮离线飞行检查：静止、起飞爬升、进近到着陆。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` / `↑` | 拉杆，抬头 |
| `S` / `↓` | 推杆，低头 |
| `A` / `←` | 左滚。在地面上也会帮助转向 |
| `D` / `→` | 右滚。在地面上也会帮助转向 |
| `Q` / `E` | 方向舵，左 / 右 |
| `X` / `Shift` / `PageUp` | 油门增加 |
| `Z` / `PageDown` | 油门减小 |
| `空格` / `B` | 刹车 |
| `C` | 机外跟随 / 座舱视角 |
| `H` | 显示或隐藏操作说明 |
| `P` | 暂停 |
| `R` | 重新开始 |
| `M` | 静音 |

画面左侧有同样的操作说明。左下角的「加油」「拉杆」点一下就会保持，再点一次松开。第一次按键或点击会启动引擎声。

## 怎么飞

1. 按住 `X` 或 `Shift` 加油门，用 `A` / `D` 保持在跑道中线上。
2. 空速大约 **110 km/h** 后轻按 `W` 抬轮，机翼放平，等它自己离地。
3. 转弯时带一点拉杆，避免掉高度。松杆后飞机会慢慢改平。
4. 失速警告出现时，松开拉杆、加油门、放下机头。
5. 降落时让机场保持在前方，空速大约 **120 km/h**，对准中线。离地很低时轻拉杆，把下降率收到大约 1 m/s 再接地。
6. 接地太重、机翼没有放平、偏出跑道、撞山或掉进湖里，都会坠毁。按 `R` 回到跑道头。

跑道方向是北南向，号为 **36 / 18**。侧方的坡度灯会随你的进近角度在红白之间变化：太高偏白，太低偏红。

## 已实现

- 轻型教练机：俯仰、滚转、偏航、油门、刹车，螺旋桨和舵面随操作摆动
- 升力、阻力、重力和螺旋桨推力；低速大迎角会失速，贴近地面有一点地面效应
- 跑道、停止道灯、进近灯、坡度灯、停机坪、机库、塔台、风袋和另一架停着的飞机
- 草地、山、湖、树和云
- 空速、海拔、离地高度、航向、升降率、油门、转速和姿态仪
- 小地图、返回机场的方位提示
- 平稳着陆、硬着陆和坠毁后重飞
- 引擎、风声和失速警告音

这是街机手感，不是适航模拟。没有多人、天气系统或完整航电。
